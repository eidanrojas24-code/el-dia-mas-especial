# El día más especial — para Zareth
HTML + CSS + JS puros. Sube la carpeta a GitHub y actívala con GitHub Pages.
- Textos, fechas, cuenta regresiva, tarjetas y carta: `config.js`
- Música: `assets/audio/dream-of-you-amaria.mp3`
- Muñequitas (opcionales): `assets/images/doll-headphones.webp`
- Mapa estelar para imprimir: `assets/Mapa_Estelar.svg`

- Probar en local: doble clic en `iniciar.bat` (usa Python si lo tienes; si no, PowerShell) (abre http://localhost:3000). No hace falta para GitHub Pages.
- Cuenta regresiva: `config.js` → `countdown.target`.
- Canción de la carta: `assets/audio/te-amo-y-mas-diego-luna.mp3` (suena al abrir la carta)
